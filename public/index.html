API Documentation

RESTful API for adding professional watermarks to images. All processing is done in-memory with no file storage.

📤 Upload from File

POST /upload

Upload an image file and add watermark

Request (multipart/form-data):

{
  "image": File,           // Image file (required)
  "address": String,       // Custom address (optional)
  "format": "binary|json"  // Response format (optional, default: binary)
}

cURL Example:

curl -X POST http://localhost:3000/upload \
  -F "image=@photo.jpg" \
  -F "address=Jl. Sudirman No. 123, Jakarta" \
  -o watermarked.jpg

🌐 Upload from URL

POST /upload-url

Download image from URL and add watermark

Request (application/json):

{
  "url": "https://example.com/image.jpg",  // Image URL (required)
  "address": "Custom address",              // Custom address (optional)
  "format": "binary"                        // Response format (optional)
}

cURL Example:

curl -X POST http://localhost:3000/upload-url \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/image.jpg",
    "address": "Jl. Sudirman, Jakarta",
    "format": "json"
  }'

💚 Health Check

GET /health

Check API server status

Response:

{
  "success": true,
  "message": "Service is healthy",
  "timestamp": "2025-11-11T12:00:00.000Z",
  "data": {
    "uptime": 12345,
    "memory": {...}
  }
}

Response Formats

Binary Response (default)

Returns processed image as binary data

Content-Type: image/jpeg
Content-Length: 1234567
Content-Disposition: inline; filename="watermarked-image.jpg"
X-Original-Size: 987654
X-Processed-Size: 1234567

JSON Response

Returns base64 encoded image in JSON

{
  "success": true,
  "message": "Image processed successfully",
  "timestamp": "2025-11-11T12:00:00.000Z",
  "data": {
    "image": "data:image/jpeg;base64,/9j/4AAQ...",
    "size": 1234567,
    "originalSize": 987654
  }
}

⚡ Rate Limiting

  • 100 requests per 15 minutes per IP address
  • Rate limit headers included in response
  • Returns 429 status when limit exceeded

📋 Requirements

  • Supported Formats: JPG, JPEG, PNG, WebP
  • Max File Size: 10MB
  • Address Length: Max 500 characters
  • URL Validation: Must be valid HTTP/HTTPS URL
